Insecure Direct Object Reference (IDOR)

OWASP A01 · Broken Access Control | CWE-639

Definition

Insecure Direct Object Reference (IDOR) happens when an app lets a user access a record without checking if they have permission to see it. In this lab, a signed-in user can see someone else’s profile by entering their ID.

Impact

IDOR can expose private records, such as personal profiles or financial documents. In 2019, a journalist reported that changing the document ID in a First American Title link let him view other customers’ documents. Some contained Social Security numbers and banking information.

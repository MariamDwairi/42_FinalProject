Definition

Mass Assignment is a vulnerability that occurs when an application automatically copies user-provided data into an object without restricting which fields can be modified.
Attackers can exploit this by adding unexpected parameters to http request, allowing them to change protected information such as account permissions, grades, or payment details.

const student = {

    email: "benito@std.edu",
    gpa: 2.1,
    tuitionDue: 4000

function updateProfile(input) {
    Object.assign(student, input); // BUG
    return student;
}
const student = {

    email: "benito@std.edu",
    gpa: 2.1,
    tuitionDue: 4000

function updateProfile(input) {
    const allowed = ["name", "email"];
    const safe = Object.fromEntries(
        Object.entries(input).filter(
            ([key]) => allowed.includes(key) // FIX
        )
    );
    Object.assign(student, safe);
    return student;
}

Impact

Mass Assignment can lead to unauthorized modification of sensitive data, privilege escalation, and security breaches. A real example occurred in 2012, when an attacker exploited a Mass Assignment vulnerability in GitHub to add his own SSH public key to the Rails organization, allowing him to push code to a repository without authorization.
